# Nexys4 DDR 上板验收清单

## 开始条件

组长和 B 先提供接通 CPU、VGA、PS/2 的集成提交及可打开的 Vivado 工程。当前主线 `ee83409` 具备基础 MMIO，键盘寄存器和 VGA 显存仍等团队接入。集成后核对以下接口及接线。

- CPU 读写 `0xFFFF0000–0xFFFF0FFF` 进入寄存器区。显存写入 `0xFFFF1000–0xFFFF22BF` 进入帧缓冲，两条路径互斥。核对 `sw` 写相邻两格、`sh` 保留相邻半字和帧缓冲字节使能。
- 键盘 FIFO 保留原始扫描码，`KEY_DATA` 只在有效读取时弹出一字节，`KEY_STATUS` 溢出位读清。确认一条访存指令只产生一次有效弹出。
- 记录输入时钟、CPU 时钟及 VGA 像素时钟。若沿用 100 MHz 主时钟和原分频器，`CPU_CLOCK_INTERVAL=25` 对应候选 2 MHz。用最终实现的时序结果确认频率和跨时钟域处理。
- 电脑接板卡编程 USB 口，显示器接 VGA，USB 键盘接板载 USB HOST。Nexys4 DDR 的板载 HID 控制器在 FPGA 一侧提供 PS/2。 [Digilent Nexys4 DDR 参考手册](https://digilent.com/reference/_media/reference/programmable-logic/nexys-4-ddr/nexys4ddr_rm.pdf)

## 在 Vivado GUI 加载镜像

1. 打开组长提供的集成 `.xpr`，在 **Sources** 中确认当前顶层和约束。找到顶层里的 CPU 实例，按本轮要验证的镜像改 `MEM_FILE`。基线顶层中的这个参数在 `RedirectPipelineRiscV #(...)` 上。若集成版本把镜像配置移到其他文件，以最终工程入口为准。
2. 使用能够从综合目录访问的路径。下面示例以仓库位于 D:/fpga 为例。按本机克隆位置改前缀，切换镜像时改末尾文件名。综合日志应成功读入对应文件。 [Vivado UG901 的存储初始化说明](https://docs.amd.com/r/en-US/ug901-vivado-synthesis/Loading-Memory-Contents-With-File-I-O-Tasks)

   ```verilog
   .MEM_FILE("D:/fpga/Hardware-training-FPGA-/software/tetris/delivery/镜像/diag_mmio.mem")
   ```

3. 保存后执行 **Run Synthesis → Run Implementation → Generate Bitstream**，核对日志、DRC 和实现时序。用 **Open Hardware Manager → Open Target → Auto Connect → Program Device** 选择本轮生成的位流。每次更换镜像后重新生成位流，记录镜像文件、集成提交和位流文件名。
4. 按下面顺序集中验收。每个镜像先将 `SW[15]` 置 1 选 MMIO LED，按 BTNU 复位，完成该行后再切换镜像。若结果不符，先记下失败镜像和现象，留存相关截图或 ILA 数据。

| 顺序 | 镜像 | 操作与通过条件 |
| --- | --- | --- |
| 1 | [diag_mmio.mem](镜像/diag_mmio.mem) | 使用 `SW[2:0]=111` 选 MMIO 数码管，再拨几位开关核对 LED 镜像。`SW[14]=0` 时数码管显示 `12345678`，置 1 后显示持续变化的节拍。 |
| 2 | [diag_vga.mem](镜像/diag_vga.mem) | LED 为 `0202`。首格是白色 A，第二格是黄色 C，首行最右为红块、下一行最左为绿块，右下角是紫色 Z。同时观察数码管是否被显存写入误改。 |
| 3 | [diag_key.mem](镜像/diag_key.mem) | LED 为 `0203`。单独按下再松开左键，屏幕第 2 行依次显示 `E0 6B E0 F0 6B`，第 3 行仅在按下码对应位置显示 `01`。再试右键，逻辑号应为 `02`。 |
| 4 | [game_demo.mem](镜像/game_demo.mem) | LED 为 `600D`。按[演示脚本](演示脚本.md)验开局、双行消除、300 分、暂停保持和重开。继续每次按空格把 10 个 O 堆在出生列，观察 `GAME OVER`。若需演示升级，从新局把五块消两行的流程连续重复五次，检查 `LINES=10`、`LEVEL=2`、`SCORE=1500`。 |
| 5 | [game.mem](镜像/game.mem) | 核对正式出块、左右移动、旋转、软降、硬降、暂停或恢复、重开、`ESC` 和 BTNU。连续运行至少 5 分钟，记录画面、操作响应、异常及重开或复位后的表现。 |

所有镜像若显示 `E001`，优先核对 `SYS_ID` 的返回值与 MMIO 译码。游戏显示 `EXITED` 后，按 BTNU 才会再次开局。
