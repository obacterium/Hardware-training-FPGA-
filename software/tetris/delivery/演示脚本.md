# FPGA 俄罗斯方块演示脚本

答辩演示约两分钟。板上用 `game_demo.mem` 演示固定双行消除，用 `game.mem` 展示正式出块和旋转。两个镜像可预先各生成一个 bitstream，现场按顺序烧录。若现场只留一个 bitstream，播演示镜像并展示正式版仿真结果。

## 开局、消行与重开

1. 烧录演示位流后按 BTNU 复位，打开拨码 `SW[15]` 观察 LED `600D`。屏幕显示方框、黄色 O、分数 0、行数 0、等级 1、`PLAYING` 和操作提示。
2. 按一次左键再按一次右键，说明短按横移。按一次下键观察软降。按 `R` 回到相同的开局状态。
3. 从每个 O 块的出生位置开始，按下表逐个放置。每次单独短按方向键，等画面移动后再按下一次。移动到相应的两列后按空格硬降。

| 第几个 O | 从出生位置移动 | 落到的列（从左数） |
| --- | --- | --- |
| 1 | 左 4 格 | 第 1、2 列 |
| 2 | 左 2 格 | 第 3、4 列 |
| 3 | 原位 | 第 5、6 列 |
| 4 | 右 2 格 | 第 7、8 列 |
| 5 | 右 4 格 | 第 9、10 列 |

第五个落定后，底部两行消除，预期读数为 `SCORE 300`、`LINES 2`、`LEVEL 1`。

4. 按 `P` 后等 1 秒。状态变为 `PAUSED`，棋盘与分数保持。松开并再次按 `P`，状态恢复 `PLAYING`。按 `R` 清除棋盘、分数和行数，重新开局。
5. 切换到正式镜像，等到一个 I、T、S、Z、J 或 L 出现在远离堆叠和边界的位置，短按上键展示旋转。最后按 `ESC` 显示 `EXITED`，按 BTNU 重新开局。

建议讲解顺序为输入经板载 USB HID 桥和 PS/2 FIFO，CPU 轮询解码并更新棋盘，汇编程序只把改变的字符对写入 VGA 帧缓冲。第五块落定时指向屏幕的分数和行数，随后暂停和重开。

## 仿真复演

在已构建镜像的仿真目录运行 `xsim test_game_demo -runall -testplusarg capture_frames`。对应的 testbench 依次注入同样的方向键和空格扫描码，并执行含暂停、判负、退出和复位的完整回归。 [仓库构建与仿真说明](../README.md) · [已采集的开局及消行画面](验证证据/双行消除仿真画面.png)
